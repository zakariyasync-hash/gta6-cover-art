Neon Coast Cover Studio — an offline web app that turns any photo and caption into multi-panel GTA-style cover art: six layouts (Vice Grid, Hero + Three, Full Bleed, Comic Strip, Tilted Snaps, Nine Panel), five sunset and neon colour grades, crop and position per panel, bold Anton / Bebas Neue poster lettering with a Pacifico script subtitle, film grain and vignette, and PNG export at 1080 x 1080, 1080 x 1350 and 1920 x 1080. Everything runs from local files — photos never leave the machine, no Rockstar logos, artwork or fonts (all fonts are SIL OFL, vendored under app/fonts/).

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
